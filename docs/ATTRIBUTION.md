## How to credit LOCI

If you use, redistribute or build on this project, please:

1. Keep the `LICENSE` file and its copyright line (the MIT License requires this).
2. Credit Arko Sanyal as the principal author, and the contributors listed in
   [`AUTHORS.md`](../AUTHORS.md).
3. Link to the canonical repository: <https://github.com/arko-sanyal-loci/LOCI-MEMORY-ENGINE>.
4. Where the hash-chained credit ledger matters to your use, reference
   [`ledger/credit_ledger.jsonl`](../ledger/credit_ledger.jsonl).

Example:

```
Based on the LOCI Memory Engine by Billo Tech
© 2026 Billo Tech / Arko Sanyal, MIT License
https://github.com/arko-sanyal-loci/LOCI-MEMORY-ENGINE
```
