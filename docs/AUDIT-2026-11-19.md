## Broken code that was fixed

### 1. MCP server and HTTP bridge could not start

`mcp_server.py` and `sovereign_bridge.py` import `route_inference` (and the bridge also
`OLLAMA_ENDPOINTS`) from `gpu_governor.py`. Commit `acfc491` (2026-11-04) replaced
`gpu_governor.py` with a version that no longer had either, so both modules raised
`ImportError` at import. `systemd/loci-mcp.service` uses `Restart=always`, so on a machine running
that unit it would restart in a loop.

Evidence: `python -c "import loci_engine.mcp_server"` →
`ImportError: cannot import name 'route_inference' from 'loci_engine.gpu_governor'`.
Nothing in the test suite imported `mcp_server`, which is why CI stayed green.

Fix: restored `route_inference()` and `OLLAMA_ENDPOINTS` from the pre-`acfc491` version (the
`.stale-vulkan-*.bak` file), with endpoints overridable by `LOCI_RTX_ENDPOINT` and
`LOCI_ARC_ENDPOINT`. The Arc default stays `:11435`, which `acfc491`'s own commit message
confirms is where llama.cpp SYCL serves on station-0. New test: `test_mcp_server_over_stdio`.

### 2. RAG pipeline could not start

`rag/pipeline.py` imports `loci_engine.vectors.VectorStore`, but `vectors.py` was never ported
from `loci-memory-engine-1` when `rag/` was.

Fix: ported `vectors.py`, its 13 tests and the 5 pipeline tests (skipped without Ollama). The legacy file used the old heat law (0.95/day
exponential, 0–1 without a floor). The port uses the canonical law from `heat.py`
(tier-aware hyperbolic decay, bounded by `ALPHA_FLOOR` and `HEAT_CEILING`), so RAG chunks and
memory items now age the same way.

### 3. First run failed without `~/loci-memory-engine/`

`StorageEngine()` with the default path raised `sqlite3.OperationalError: unable to open database
file` when the folder did not exist. It now creates the parent folder.

### 4. CI skipped a quarter of the tests and could not fail on install

`.github/workflows/ci.yml` ran `python -m unittest discover`, which does not collect plain
pytest functions: the 42 `coordination_bus` tests never ran in CI. The install step ended in
`|| true`, so a broken install was invisible. Now: pytest, a byte-compile step, a 3.11/3.12/3.13
matrix, and no `|| true`. The trigger on the `reconcile` branch was dropped, per the note in
`REPO_STRUCTURE.md`.

### 5. `mcp` 2.x breaks the coordination bus binding

`mcp` 2.x renamed `FastMCP`. An unpinned install made `coordination_bus.mcp_server.mcp` silently
`None`, which is why `test_mcp_tool_discovery` failed. `pyproject.toml` pins `mcp>=1.2,<2`, and
the test now skips with a clear reason when the extra is not installed.

## Found, not changed (needs a decision)

1. **HOT threshold 0.70 vs 0.80.** Both are in `heat.py` for different jobs; see
   [ARCHITECTURE.md](ARCHITECTURE.md#heat-tiers-and-the-070-vs-080-question).
2. **Root ops scripts** (`harden_vps.sh`, `node_sync.sh`, `push_station0.sh`, `sync_to_remote.sh`,
   `audit_connectivity.sh`, …) should move to `scripts/ops/`, but cron jobs or shell history on
   the machines may call them by path. Check the machines first.
3. **`mac-install/`** (84 files) is still a flat rescue copy. It overlaps `loci_engine/`
   (e.g. `ethics_filter.py` vs `ethics.py`) and includes personal files such as
   `Arko_Profile.md` in a public repo. Decide what is public before integrating.
4. **Public-domain wording vs the patent plan.** `PAPERS.md` (old text) and the papers README say
   the defensive publications put the work in the public domain and block patenting, "including
   the author". If a patent filing is planned, have the attorney review this wording and the
   choice of licence before more is published.
5. **Branches.** `reconcile`, `arc/hybrid-inference-design`, `claude/gallant-cerf-ga088c` and
   `cursor/learning-loop-cycle-3012` are still open; see `REPO_STRUCTURE.md` §4.
6. **Dropbox gaps** (dynamic τ gate with MRR targets, the TF-IDF compressor behind the 8.89×
   claim, the value bus spec, the sealed TRS package) are not in any repo yet. Importing them is
   separate work.
7. `mcp_server.py` handles a `sync_peers` tool that `tools/list` does not advertise. Harmless,
   but one of the two should go.
