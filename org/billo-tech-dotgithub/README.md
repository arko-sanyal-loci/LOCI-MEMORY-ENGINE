# billo-tech/.github

Organization-wide files for [Billo Tech](https://github.com/billo-tech).

- `profile/README.md` is the page shown at github.com/billo-tech.
- `profile/assets/` holds the logo files it embeds (see `BRAND.md` in the engine repo for the colours and rules).
- `CONTRIBUTING.md` and `SECURITY.md` apply to every Billo Tech repository that does not have its own.

## Install (one time, by an org owner)

1. Create a **public** repository named exactly `.github` in the `billo-tech` organization.
2. Copy the contents of this folder into it and push to `main`.
3. Set the organization picture to `profile/assets/billo-tech-mark.svg` (export to PNG first; GitHub avatars do not accept SVG).

Until the main repositories are transferred into `billo-tech`, the profile links point at
`arko-sanyal-loci`. GitHub redirects those links after a transfer, so nothing breaks either way.
